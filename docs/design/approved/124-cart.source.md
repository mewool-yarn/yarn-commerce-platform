# 购物车方向与来源

- 关联：[Issue #124](https://github.com/hitoami/yarn-commerce-platform/issues/124)。用户 2026-10-03 在会话中要求按此视觉稿实现，并逐项确认下列冲突。
- 视觉稿：Claude Design 项目 `9a6e4e76-634d-4c45-80e2-477346a10abc`（购物车）中的 `Cart.dc.html`：手机 390 有商品 1a、空购物车 1d；桌面 1440 有商品 2a、空购物车 2b，简体中文。组件来自同项目的 hitoami yarn design system（`_ds/hitoami-yarn-design-system-cff99daf-…`）。
- 视觉稿中的商品、色名、价格、件数均为 demo；实现只读 Shopify 购物车数据。

## 用户确认（2026-10-03）

| 冲突 | 决定 |
|---|---|
| 视觉稿是整页，现站为右侧抽屉 | 先选整页；看过实现后改为「样式用本稿、交互沿用 Rise 抽屉」：加购与页头图标仍滑出抽屉（不离开商品页），抽屉内容按本稿条目与汇总重做，底部「查看购物车」进入 `/cart` 整页（2a / 1a）。`/cart` 页不再叠抽屉 |
| 视觉稿焦糖棕 / 奶油带 / 驼色帮助条 / 爪粉新手卡不在色板 | 复用现有角色，不新增颜色：结账、价格、继续购物用 `home-action`；奶油带与桌面汇总面板用 `bg-band`（#122 新增的暖米面板色）；帮助条同首页紧凑帮助条（`action-subtle-bg` + `cta-border`，链接 `action`）；新手卡用 `tint-blush`；次按钮用 `bg-sunken` |
| 现有三张保障条，稿中没有 | 去掉；`yarn-cart-assurance` section 保留，可在编辑器加回 |
| 店里没有作品库页和新手入门页 | 入口有链接才显示：默认只有「看全部毛线」与帮助条；「按作品图选」主按钮与新手卡在后台填链接后出现；说明改为不承诺内容的中性文案（三语可在编辑器改） |

## 与视觉稿的差异

- 商品图按 `DESIGN.md` 完整显示（`contain` 于暖砂底），不裁切。
- 税费说明沿用 Shopify 按店铺税费设置给出的原生文案（当前店铺价格不含税，显示「结账时计算税费、折扣和运费」），不写死「含税」。
- 成品条目没有规格时不显示稿中的「成品 · 规格见商品详情」；规格行只显示真实 Variant 选项与商品属性。
- 长商品名最多显示 3 行；帮助条按稿只放标题与链接，不加首页的图标。
- 抽屉没有单独视觉稿：条目沿用手机 1a，汇总沿用 1a 的小计与「去结账」；空抽屉只放睡猫、标题与「继续购物」（帮助条与新手卡留在整页）。
